# Getting started

Getting started with Divinité is quick and easy.

1. [Invite Divinité to your server](https://discord.com/api/oauth2/authorize?client_id=1473058783008653413&permissions=277025508416&scope=applications.commands%20bot)
2. Create your first event with the `/create-event` slash command
3. RSVP to the event by clicking one of the event buttons

And that's it! You've created your first event with Divinité.

## Reminders

Users who signup for an event will receive a reminder approximately 10 minutes
prior to the scheduled start time.

[Click here](/reminders/) to learn more about reminders.

## Permissions

By default, anyone can create events, though users can only edit and delete
events they own (unless they have the `Manage Server` permission).
